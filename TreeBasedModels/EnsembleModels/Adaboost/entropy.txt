Which are the probabilities of getting these combinations of colors?
blue blue blue blue -> P(red) = 0, P(blue) = 1.       1 x 1 x 1 x 1 = 1
red red red blue -> P(red) = 0.75 P(blue) = 0.25      0.75 x 0.75 x 0.75 x 0.25 = 0.105
red red blue  blue -> P(red) = 0.5 P(blue) = 0.5     0.5 x 0.5 x 0.5 x 0.5 = 0.0625
